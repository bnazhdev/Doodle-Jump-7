# Прыг-Тетрадь

Онлайн-прыгалка в духе Doodle Jump для 1–7 игроков: каждый играет со своего компьютера или телефона, все на одной карте. Весь код — один файл `index.html`, сервер не нужен.

## Как играть

1. Открыть сайт игры и ввести имя.
2. Ведущий нажимает «Создать комнату» и получает код из 4 цифр.
3. Остальные вводят код или открывают ссылку `…/#1234`.
4. Ведущий выбирает режим, длину и сложность и запускает турнир.

## Управление

| Клавиши | Действие |
|---|---|
| ← → / A D | двигаться |
| ↑ / W / пробел | стрелять |
| 1–5 | реакции 😂🔥😡👏💀 |
| K | кинуть кляксу (выбывшие в режиме «Выбывание») |
| F · M · N | полный экран · звук · музыка |

На телефоне: касание нижней половины слева или справа — движение, верхней трети — выстрел.

## Что внутри

- **Режимы:** Гонка, Король горы, Выбывание, Команды 3×3; короткий (3 уровня) или полный (8 уровней) турнир.
- **8 уровней** в разных тетрадях: математика, альбом, нотная, ночная. Потоп чернил снизу, ветер, дыры в листе, босс.
- **Враги:** кляксы, летучие мыши, стрелки, призраки, НЛО, босс.
- **Бонусы:** ракета, кеды, щит, магнит; атаки на соперников — чернила, путаница, лёд, смерч; подарки для отстающих.
- **Прогресс:** монеты, магазин шапок и следов, 17 достижений, вызов дня с общей таблицей.

## Сеть

Ведущий — хост комнаты. Игроки подключаются напрямую (PeerJS / WebRTC), а если сеть не пускает — через публичный MQTT-брокер по WebSocket. Прогресс и покупки хранятся в браузере (localStorage).

## Запуск локально

Открыть `index.html` в браузере. Для игры с друзьями файл должен лежать на хостинге, например GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.
